## Why this repository exists

My formal education gives me the foundation, but I am building an additional curriculum through self-study, documentation, simulation, projects, and debugging.

The rule:

**Learn → Build → Break → Debug → Explain → Test → Repeat**

The files here are a record of actual learning work. Early code is intentionally kept as a historical record rather than silently rewritten into a polished version.
